# 문제 해결

실제로 설치하면서 겪은 문제들을 모았어요.

## 무슨 일이 있었는지 보는 법

봇이 이상하면 제일 먼저 **실행 기록**을 보세요.

1. [claude.ai/code/routines](https://claude.ai/code/routines) → `news-message` (또는 `news-daily`)
2. **History(실행 기록)** 에서 최근 실행 클릭 → Claude가 실행한 명령과 결과가 전부 보여요.

| 기록에 보이는 것 | 뜻 | 해결 |
|---|---|---|
| `/tg 실패: HTTP Error 401` | 중계 서버 열쇠(시크릿)가 틀림 | README 8-3: 시크릿 **삭제 후 다시 추가**. 값은 메모장에서 복사 |
| `HTTP Error 403` | Cloudflare가 요청을 봇으로 의심해 막음 | `bot/gateway.py`를 고치지 않았는지 확인 (User-Agent 줄이 필요) |
| `getaddrinfo ENOTFOUND <사이트>` | 클라우드 환경이 그 사이트 접속을 막음 | README 8-2: 네트워크 액세스를 **전체** |
| `BOT_GATEWAY_URL이 비어 있음` | 환경 변수 누락 | README 8-2: 환경 변수 한 줄 확인, 예약 작업의 환경이 `news-bot`인지 확인 |
| 실행 기록 자체가 없음 | 예약 작업이 호출되지 않음 | 아래 "받았어도 안 와요" |

## 텔레그램에 "받았어"도 안 와요

- 설치 스크립트 10단계(웹훅 연결)가 끝났는지: `python setup/setup.py` 다시 실행.
- 다른 기기에서 같은 봇 토큰으로 봇을 돌리고 있으면 충돌해요. 하나만 쓰세요.
- 내 계정이 아닌 다른 사람이 봇에게 보낸 메시지는 **일부러 무시**해요 (내 채팅 ID만 통과).

## "받았어"는 오는데 결과가 안 와요

- 실행 기록을 보세요 (위 표).
- "클라우드 작업을 시작하지 못했어: routine fire 401" → 예약 작업 토큰이 틀림.
  `news-message` 편집 → API 트리거 → **Regenerate** → `python setup/setup.py` 를 `--reset` 없이 실행해도
  이미 연결된 단계는 건너뛰므로, `setup/.local.json`에서 `"routine_url"` 줄을 지우고 다시 실행하세요.

## 설치 중 문제

| 증상 | 해결 |
|---|---|
| 채팅 ID를 못 찾음 | 봇에게 메시지를 보낸 뒤 3분 안에 찾아요. 시간이 지났으면 다시 실행하고 메시지를 한 번 더 보내기 |
| `npm install` 실패 | 인터넷 연결 확인. 회사·학교망이면 휴대폰 핫스팟으로 |
| 배포 후 "주소가 아직 안 열려요" | 새 주소의 보안 인증서가 만들어지는 중. 5분 뒤 다시 실행 |
| workers.dev 하위 도메인 관련 오류 | Cloudflare 대시보드 → Workers 메뉴를 한 번 열어서 하위 도메인(내 계정 이름)을 정한 뒤 다시 실행 |
| 시크릿 추가 시 빨간 오류가 잠깐 뜸 | 보통 **경로 접두사** 칸에 뭔가 들어간 것. 비워 두기 |

## 한글이 깨져요

텔레그램으로 보낸 한글은 깨지지 않아요. Windows 터미널에서 `curl`로 직접 예약 작업을 부를 때만 깨질 수 있어요
(터미널 인코딩 문제). 시험할 때는 텔레그램으로 보내세요.

## 비밀값을 바꾸고 싶어요 (토큰 유출 등)

- 텔레그램 토큰: BotFather에서 `/revoke` → 새 토큰 → `python setup/setup.py --reset`
- 메일 앱 비밀번호: 메일 설정에서 기존 것 삭제·새로 생성 → `--reset`
- `--reset`은 처음부터 다시 묻지만, Cloudflare 서버는 덮어쓰기만 하므로 안전해요.
  다만 새 열쇠가 만들어지므로 README 8-3 시크릿과 환경 변수를 새 값으로 다시 넣어야 해요.

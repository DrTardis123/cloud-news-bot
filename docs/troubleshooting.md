# 문제 해결

실제로 설치하고 쓰면서 겪은 문제들을 모았어요.

## 무슨 일이 있었는지 보는 법

봇이 이상하면 제일 먼저 **그 대화(세션)** 를 여세요. Claude가 실행한 명령과 결과가 전부 보여요.

- 매일 수집: [claude.ai/code/routines](https://claude.ai/code/routines) → `news-daily` → **실행 기록(History)** 에서 최근 실행 클릭
- 내가 답장한 뒤: Claude 앱 → Code → 그 대화

| 기록에 보이는 것 | 뜻 | 해결 |
|---|---|---|
| `getaddrinfo ENOTFOUND <사이트>` | 클라우드 환경이 그 사이트 접속을 막음 | README 3-2: 네트워크 액세스를 **전체** |
| `SYNC 실패` | 상태를 저장소에 못 올림 | 3-1의 Claude GitHub App에 내 저장소가 포함돼 있는지 확인 |
| (메일) `/mail 실패: HTTP Error 401` | 중계 서버 열쇠(시크릿)가 틀림 | README 6-5: 시크릿 **삭제 후 다시 추가**. 값은 메모장에서 복사 |
| (메일) `HTTP Error 403` | Cloudflare가 요청을 봇으로 의심해 막음 | `bot/gateway.py`를 고치지 않았는지 확인 (User-Agent 줄이 필요) |
| 실행 기록 자체가 없음 | 예약 작업이 실행되지 않음 | `news-daily`가 켜져 있는지, 일정 시각·시간대가 맞는지 확인 |

## 답장했는데 반응이 없어요

- 클라우드 컴퓨터가 다시 켜지는 데 1~3분 걸려요. 조금 기다려 보세요.
- 대화가 오래돼서 닫혔다면 **새 대화**를 열고(저장소 = 내 저장소, 환경 = `news-bot`) 같은 의견을 보내세요.
  진행 상태는 저장소에 있어서 새 대화에서도 이어져요.
- 메시지는 **하나 보내고 답이 온 뒤** 다음 걸 보내는 게 안전해요.

## 메일 설치 중 문제 (선택 기능)

| 증상 | 해결 |
|---|---|
| `npm install` 실패 | 인터넷 연결 확인. 회사·학교망이면 휴대폰 핫스팟으로 |
| 배포 후 "주소가 아직 안 열려요" | 새 주소의 보안 인증서가 만들어지는 중. 5분 뒤 다시 실행 |
| workers.dev 하위 도메인 관련 오류 | Cloudflare 대시보드 → Workers 메뉴를 한 번 열어서 하위 도메인(내 계정 이름)을 정한 뒤 다시 실행 |
| 시험 메일 발송 실패 | 메일 앱 비밀번호·SMTP 사용 설정 확인 후 `python setup/setup.py --reset` |
| 시크릿 추가 시 빨간 오류가 잠깐 뜸 | 보통 **경로 접두사** 칸에 뭔가 들어간 것. 비워 두기 |

## 비밀값을 바꾸고 싶어요 (메일을 쓸 때만)

- 메일 앱 비밀번호: 메일 설정에서 기존 것 삭제·새로 생성 → `python setup/setup.py --reset`
- `--reset`은 처음부터 다시 묻지만, Cloudflare 서버는 덮어쓰기만 하므로 안전해요.
  다만 새 열쇠가 만들어지므로 README 6-5의 시크릿과 환경 변수를 새 값으로 다시 넣어야 해요.

## 메일을 그만 쓰고 싶어요

claude.ai 환경 `news-bot`에서 `BOT_GATEWAY_URL` 환경 변수를 지우면 다음 초안부터 대화로 와요.
Cloudflare 대시보드 → Workers에서 `news-bot-gateway`를 삭제하면 서버도 사라져요.
